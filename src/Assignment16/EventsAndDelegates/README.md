# Events and Delegates Notification System

## Overview
A simple C# console application that demonstrates the use of **Delegates** and **Events**. Users can enter a notification message, which is published by a notifier class and displayed through a subscribed event handler.

## Features
- Custom delegate implementation
- Event declaration and subscription
- Event invocation
- User input handling
- Console-based notifications

## Project Structure

```text
EventsAndDelegates

```

## Concepts Demonstrated
- Delegates
- Events
- Publisher-Subscriber Pattern
- Encapsulation
- Event Handling

## Sample Output

```text
Enter notification message
Hello World

```

## Technologies Used
- C#
- .NET Console Application
- Object-Oriented Programming (OOP)

## Conclusion
This project provides a basic understanding of event-driven programming in C# using delegates and events, demonstrating communication between a publisher and subscriber.
