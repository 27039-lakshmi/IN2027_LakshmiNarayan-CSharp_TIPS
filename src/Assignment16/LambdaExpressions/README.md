# Lambda Expressions and Statements

## Overview

A simple C# console application that demonstrates the use of **Lambda Expressions** and **Lambda Statements** with LINQ. The application filters even numbers from a list of integers and then squares the filtered numbers before displaying the results.

## Features

- Integer list declaration and initialization
- Filtering data using the `Where()` LINQ method
- Data transformation using the `Select()` LINQ method
- Lambda expressions and lambda statements
- Console-based output

## Conclusion

This project demonstrates how lambda expressions and lambda statements can be used with LINQ to efficiently filter and modify collections of data. It showcases filtering even numbers using `Where()` and transforming them using `Select()`.
